## 1. CÔNG VIỆC ĐÃ HOÀN THÀNH TRONG TUẦN 3
Theo đúng tiến độ đề cương, tuần 3 em đã tập trung giải quyết bài toán: *"Nghiên cứu sử dụng AI trong phát triển phần mềm"*.
*   **Nghiên cứu lý thuyết API:** Tìm hiểu cách thức hoạt động của LLM (Large Language Model) và cơ chế tích hợp AI thông qua RESTful API.
*   **Thiết kế kiến trúc hệ thống:** Xác định luồng kết nối giữa Client $\rightarrow$ Backend  $\rightarrow$ AI Server $\rightarrow$ Database.
*   **Prompt Engineering:** Xây dựng và kiểm thử thành công các bộ System Prompt tối ưu hóa cho 3 tính năng: Phân rã công việc, Ước lượng thời gian và Tóm tắt lịch sử. Ép định dạng đầu ra thành JSON để thuận tiện cho việc code ở các tuần sau.
